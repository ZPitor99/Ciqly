# Notice d'attribution - Classes php-vite

## Utilisation de code tiers

Ce projet utilise 3 classes PHP provenant du dépôt [php-vite](https://github.com/mindplay-dk/php-vite) créé par mindplay-dk.

### Emplacement dans le projet

Les classes modifiées se trouvent dans : `src/php/class/php_vite/`

### Contributeurs originaux

Ces classes ont été développées par :
- **Rasmus Schultz** (mindplay-dk)
- **Thomas Müller** (mimmi20)
- **Brian Angulo** (brianangulo)

### Modifications apportées

**Date des modifications** : Avril 2026

Les modifications suivantes ont été apportées aux classes originales :

1. **Suppression de la dépendance à Composer et du `namespace`** : Les classes ont été adaptées pour fonctionner sans gestionnaire de dépendances Composer.

2. **Amélioration de la méthode `createStyleTags` dans `Manifest.php`** : Ajout de l'attribut `type='text/css'` pour plus de rigueur dans la génération des balises de style.

3. **Ajout de commentaires d'attribution** : Dans chacune des 3 classes, un commentaire a été ajouté en en-tête pour indiquer :
    - Que ces classes proviennent du dépôt php-vite
    - Le lien vers le dépôt original : https://github.com/mindplay-dk/php-vite
    - Les noms des 3 contributeurs principaux
    - La date d'intégration dans ce projet : Avril 2026
