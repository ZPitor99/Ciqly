# Ciqual Table 2025 - Ciqly Presentation Website

*[Lire en français](README.md)*

## Description

Presentation website for the nutritional data of the Ciqual Table 2025.

This project allows users to browse and explore nutritional information for foods made available by ANSES (French Agency for Food, Environmental and Occupational Health & Safety).

The explanatory file covering the database design and Ciqual data processing is located in the documentation folder: [DF_ciqual](DF_database_ciqual.md)

## Technologies Used

- **HTML5** - Page structure
- **CSS3** - Styling and design
- **JavaScript** - Interactivity
- **Alpine.js** - Lightweight JavaScript framework
- **PHP** - Server-side programming
- **SQL/PLSQL** - Relational database (PostgreSQL)
- **JSON** - Data exchange format
- **XML** - Structured data format
- **Python** - XML processing
- **PhpStorm - PyCharm - WebStorm** (JetBrains) — Development environment

## Data Source

The data and information from the Ciqual Table and Average Foods 2025 are made available to the public by the French Agency for Food, Environmental and Occupational Health & Safety (Anses).

## Terms of Use

The reuse of information published on the Anses-Ciqual website is subject to the condition that such information is not altered, that its meaning is not distorted, and that the source and version are mentioned, in accordance with the provisions of French Law No. 2016-1321 of October 7, 2016 for a Digital Republic, and the code governing relations between the public and the administration.

Ciqual table data is open to the public and freely downloadable.

## Installation

```bash
# Clone the project
git clone https://github.com/ZPitor99/Ciqly

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Production Build

```bash
npm run build
```
